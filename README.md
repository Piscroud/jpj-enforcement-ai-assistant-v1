# JPJ Enforcement AI Assistant V1

Versi GitHub Pages bagi sistem rujukan JPJ Enforcement AI Assistant.

## GitHub Pages
Workflow GitHub Actions di `.github/workflows/pages.yml` akan menerbitkan kandungan repository ke GitHub Pages apabila perubahan dimuat naik ke branch `main`.

## Keperluan AI
Mod AI menggunakan Gemini melalui panggilan API dari browser. API key tidak disimpan dalam repository; pengguna perlu menyediakan API key pada runtime melalui tetapan aplikasi.

## Nota
Sistem ini ialah sistem rujukan dan tidak menggantikan Pegawai Penyiasat atau Penasihat Undang-Undang.

Aplikasi menggunakan CDN untuk Tailwind CSS, Font Awesome dan Google Fonts, serta logo JPJ daripada Portal Rasmi JPJ.
